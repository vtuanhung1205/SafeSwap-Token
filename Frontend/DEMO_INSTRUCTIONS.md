# 🎯 SafeSwap Demo Instructions

## Demo Mode Features

### **1. Wallet Connection Demo**
- ✅ Connect any Aptos wallet (Petra, Martian, etc.)
- ✅ Works even with 0 APT balance
- ✅ Shows "Demo Mode" badge when no balance
- ✅ Displays wallet address and connection status

### **2. Token Swap Demo**
- ✅ Select any tokens from Panora Exchange list
- ✅ Enter any amount for swap
- ✅ Simulates swap with 5% slippage
- ✅ Saves demo transaction to history
- ✅ No real blockchain transaction needed

### **3. Transaction History Demo**
- ✅ View real transaction history from blockchain
- ✅ Shows demo transactions with "demo_" prefix
- ✅ Displays transaction hash, type, timestamp

### **4. Token List Demo**
- ✅ Browse all Aptos tokens from Panora Exchange
- ✅ Filter by token types (Native, Emojicoin, Meme)
- ✅ Search tokens by name or symbol
- ✅ View token details (address, decimals, tags)

## How to Demo

### **Step 1: Connect Wallet**
1. Click "Connect Wallet" button
2. Choose any available wallet (Petra recommended)
3. Approve connection in wallet
4. See "Demo Mode" badge if no balance

### **Step 2: Try Token Swap**
1. Go to "Swap" tab in dashboard
2. Select "From" token (e.g., APT)
3. Select "To" token (e.g., USDT)
4. Enter amount (any amount works in demo)
5. Click "Swap" - will show demo success message

### **Step 3: View History**
1. Go to "History" tab
2. See real transactions from blockchain
3. Demo transactions will show "demo_" prefix

### **Step 4: Browse Tokens**
1. Go to "Tokens" tab
2. Browse all available Aptos tokens
3. Use filters to find specific token types
4. Search for tokens by name

## Demo Mode Benefits

- 🚀 **No Real Money Needed**: Demo with 0 balance
- 🔒 **Safe Testing**: No real transactions
- 📊 **Full Functionality**: All features work in demo
- 💾 **Data Persistence**: Demo transactions saved
- 🎨 **Visual Indicators**: Clear demo mode badges

## Real Mode vs Demo Mode

| Feature | Demo Mode | Real Mode |
|---------|-----------|-----------|
| Wallet Connection | ✅ Works with 0 balance | ✅ Requires real wallet |
| Token Swap | ✅ Simulated swap | ✅ Real blockchain transaction |
| Transaction History | ✅ Shows demo + real | ✅ Shows real transactions |
| Token List | ✅ Full access | ✅ Full access |
| Balance Display | ✅ Shows "Demo Mode" | ✅ Shows real balance |

## Switching to Real Mode

To use real transactions:
1. Add APT to your wallet
2. Reconnect wallet
3. Demo mode will automatically disable
4. All swaps will be real blockchain transactions
